# Galaksion Kube Deploy Manager — plugin repository

Custom JetBrains plugin repository for **Galaksion Kube Deploy Manager**.

## Install in your IDE

1. `Settings | Plugins | ⚙ | Manage Plugin Repositories…`
2. Add the URL:
   ```
   https://raw.githubusercontent.com/BlenderRUS/glx-kube-deploy-dist/main/updatePlugins.xml
   ```
3. Open the **Marketplace** tab, find **Galaksion Kube Deploy Manager**, install.

New versions are delivered as IDE updates automatically once published here.
